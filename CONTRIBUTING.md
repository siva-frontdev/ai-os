# Contributing

## Development Setup

1. Run `./scripts/setup.sh` to install dependencies.
2. Follow the project structure conventions.
3. Write tests for new features.
4. Run all tests before submitting.

## Code Style

- Follow language-specific style guides (rustfmt, gofmt, prettier).
- Keep functions focused and small.
- Document public APIs.
- Use conventional commits.

## Pull Request Process

1. Create a feature branch from `main`.
2. Commit with clear messages.
3. Open a PR with a description of changes.
4. Ensure CI passes.
